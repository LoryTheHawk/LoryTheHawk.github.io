# Fonts

Self-hosted latin subsets of [Fraunces](https://github.com/undercasetype/Fraunces), [Inter](https://github.com/rsms/inter) and [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), downloaded from Google Fonts.

All three are licensed under the SIL Open Font License 1.1: see the `OFL-*.txt` files in this folder.
