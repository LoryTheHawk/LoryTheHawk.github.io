# 🦅 lorythehawk.github.io

Personal website of **Lorenzo Ferraioli** — M.Sc. Banking & Finance student at UCSC Milan, on exchange at Kozminski University, Warsaw.

👉 **Live:** https://lorythehawk.github.io

## ✨ Features

- 📈 A playful animated "stock chart" of my career (hover the dots!)
- 📰 Finance ticker tape with very serious market data (COFFEE ▲ +42%)
- 🇮🇹 / 🇬🇧 Language switch and ☀️ / 🌙 light-dark theme
- 🎬 Count-up stats, skill bars and scroll animations
- 🦅 Easter egg: click the logo in the top-left corner

## 🛠️ Built with

Plain **HTML, CSS and JavaScript** — no frameworks, no build step. Hosted for free on **GitHub Pages**.

```
index.html   → content (English)
style.css    → design, themes, animations
script.js    → Italian translations, chart, ticker, interactions
```

Run it locally by simply opening `index.html` in your browser.
